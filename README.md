# 📋 Smart Task Manager Web Application

A simple and interactive task management web application built using HTML, CSS, and JavaScript.

## 🚀 Features
- Add, edit, and delete tasks
- Set date and time for tasks
- Mark tasks as completed
- Persistent data using Local Storage
- Responsive UI with basic animations

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript


## 📌 How to Use
1. Enter a task with date and time
2. Add the task
3. Edit, delete, or mark as completed
